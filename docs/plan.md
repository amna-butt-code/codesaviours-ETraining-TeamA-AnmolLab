# Project Plan — Anmol Lab

## Objective
Build a client-ready diagnostic laboratory website with a searchable test catalog, online booking, home sample collection requests, secure reports, role-based portals, admin management and carefully constrained AI assistance.

## Sitemap
Home, About, Tests, Test detail, Packages, Package detail, Book a Test, Home Sampling, Download Report, Branches, For Doctors, Blog, FAQ, Contact, Patient Portal, Doctor Portal, Staff Portal, Admin, Privacy, Terms.

## Core user journeys
1. Visitor searches a test → reviews preparation/sample price → signs in → books branch/home collection → receives booking code.
2. Staff/admin opens booking → updates sample status → uploads private report → patient sees report-ready status and downloads after authorization.
3. Admin maintains test catalog, package, branches, staff and contact messages.
4. Doctor sees only reports for patients explicitly assigned as referrals.
5. Patient uploads prescription → OCR/vision detects possible test names → patient confirms before adding. (Integration point documented; OCR provider still needs to be configured.)
6. Patient requests report explanation → explicit consent → safe explanation of test terminology only. (Integration point documented; clinical safety review required.)

## Feature ownership
To be completed by Day 1 lead after team agreement. Each member must own at least one complete end-to-end feature.

## Milestones
See the supplied internship brief: 2–7 Nov foundation and booking; 9–14 Nov reports, portals, AI, hardening, testing and delivery.
